# my-circuit

一个在浏览器里搭逻辑电路的小游戏。

没有关卡，也没有必须完成的任务：给你一堆开关、逻辑门和灯泡，自己接出想要的东西，然后看它跑起来。

## 开始玩

打开 **https://www.kuiperbelt.tech/** 就能玩。不用安装，不用注册，不用登录。

## 你可以做什么

- 从左侧元件栏拖出元件放到图纸上，再用电线把它们连起来。
- 开关、按钮、时钟、常量 1 负责给出 0/1 信号。
- 用 NOT、AND、OR、DELAY 把信号组合、变换，最后接到灯泡上看结果。
- 点一下开关，灯泡会立刻亮起或熄灭——电路是持续运行的。
- 想做大一点：用"框"把图纸分区，把自己的电路封装成一个新元件，之后就能像普通元件一样反复使用。

## 上手建议

1. 先接最简单的：开关 → 灯泡，点开关看灯亮。
2. 中间加一个 NOT，看灯泡反过来。
3. 试着用两个开关加一个 AND，体会"两个都按下才亮"。
4. 熟练之后可以往半加器、锁存器、计数器方向走——只要用基础元件组合得出来，就能做。

## 往远处看

这个沙盒没有内置 CPU，也没有任何"特殊元件"替你完成计算。不过已经有人只用这里的基础门，就搭出了一台能跑程序的 8-bit 计算机。

所以如果你有耐心，也许可以自己试试：从一个寄存器开始，到指令、时钟、内存，一层层往上搭。搭不出来也没关系——做一个会闪的灯，同样很有意思。

## 一些便利

- 图纸会自动保存在当前这个浏览器里，关掉页面下次打开还在。想从头开始，点顶部的"新建"。
- 顶部工具栏可以复制、删除；选中对象后按 Ctrl/Cmd+C 也能进入复制状态；编辑支持最近 10 步的后退和前进。
- 同一时间只在一个标签页里编辑，避免两边互相覆盖。
