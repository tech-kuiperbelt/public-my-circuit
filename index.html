Session 错误

页面未能启动

本项目使用原生 ES modules，浏览器不允许通过 file:// 加载模块。

请在项目根目录运行 ./start.sh，再打开 http://127.0.0.1:8000/；不要直接双击 index.html。

如果已经通过 HTTP 打开，请按 F12 查看 Console 里的模块加载错误。
